# 一念之间 · 清静经｜十八集双语漫画电子书

在线阅读：https://zctpy.github.io/niepanmiaoxinjing/qingjing/

## 内容

18集已确认版本的中英双语漫画，人物为沈一、林晚和弥音。第一集采用弥音完全人类外观的修订版；第6集起沿用放大经文区的确认版；第18集为三人和解相拥的终章。

## 阅读功能

- 独立封面与18集完整目录；点击目录直接跳到任意一集。
- 上一集/下一集、键盘左右方向键、集数滑动条。
- 可滚动放大阅读（100%–300%），浏览器原生双指缩放。
- 浅色/夜读，当前阅读位置保存在当前设备浏览器中。
- 保存单集WebP图片、复制单集分享链接。
- 手机与桌面响应式排版，图片按需加载。

## 运行和维护

无构建步骤，无第三方脚本、CDN或运行依赖。直接打开 `index.html` 即可阅读，或用任意静态服务器运行。`episodes.json` 是内容清单，`episodes.js` 是相同内容的浏览器版本；若修改标题、图片或经文，两者应保持同步。

`assets/episode-01.webp` 至 `episode-18.webp` 为完整画幅阅读图片（原尺寸，WebP quality 94），`thumb-01.webp` 至 `thumb-18.webp` 为目录缩略图。图片中的中英文字已嵌入图像，网页不会重排或替换这些对白。经文的可复制文字另列于每集图像下方。

原图中仍可能存在AI生成文字或翻译的不足，正式出版前应逐页复校。网页本次完整保留已确认的漫画内容。
